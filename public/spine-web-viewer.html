What the Spine web viewer supports

  • Spine JSON and SKEL skeleton files.
  • Atlas text files and texture images.
  • Animation selection and browser playback controls.
  • Permanent web links for shared previews.

Spine web viewer workflow

Upload the skeleton, atlas, and texture files, then use the animation list to review playback. When the preview looks correct, create a permanent URL and send it to anyone who needs to inspect the Spine animation in a browser.

Spine web viewer FAQ

What is a Spine web viewer?

A Spine web viewer opens Spine animation files in a browser so teams can review playback without installing a desktop tool.

Can Spine-Link share a web viewer preview?

Yes. Spine-Link can publish a permanent browser preview link for a Spine animation package.
