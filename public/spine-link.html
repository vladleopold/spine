Spine-Link

Spine-Link is an online Spine preview tool and Spine web viewer. It opens Spine JSON or SKEL skeleton files with atlas and texture images, previews animation playback in the browser, and creates permanent preview links for sharing.

What Spine-Link does

  • Previews Spine JSON and SKEL animation files in a browser.
  • Loads atlas files with PNG, JPG, or WEBP textures.
  • Creates permanent links for animation review.
  • Works as a lightweight web viewer for artists, animators, and game developers.

Who uses Spine-Link

Spine-Link is useful for game teams, UI animators, technical artists, and freelancers who need a fast way to check Spine exports outside the editor. A shared preview link is easier to review than a zip archive because the animation opens directly in a browser.

Spine-Link file support

  • Skeleton files exported as JSON or SKEL.
  • Atlas files exported from Spine.
  • Texture pages in PNG, JPG, JPEG, or WEBP format.
  • Multiple animation names from the same skeleton.
