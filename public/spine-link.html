Spine-Link

Spine-Link is an animation portfolio platform for Spine work. It opens Spine JSON or SKEL files with atlas and textures, creates anonymous preview links, lets users sign in with Google, saves works to an account-backed portfolio database, and publishes public portfolio pages with likes, views, archive listings, and video metadata.

What Spine-Link does

  • Previews Spine JSON and SKEL animation files in a browser with atlas and texture files.
  • Creates anonymous permanent preview links through the Create preview upload flow.
  • Supports Google account login and registration for saving uploaded works.
  • Stores works in an account-backed portfolio database with public and private profile modes.
  • Publishes public portfolio works to World SPINE ARCHIVE with real likes and views.
  • Provides dedicated video pages with VideoObject metadata for Google Video Search.

Profiles and archive

A Google-account profile can be a public portfolio, where visible works are searchable and can appear in World SPINE ARCHIVE, or a private library, where uploaded work is stored for the owner and is not listed through the site or Google by default.

File support and origin proof

  • Skeleton files exported as JSON or SKEL.
  • Atlas files exported from Spine.
  • Texture pages in PNG, JPG, JPEG, or WEBP format.
  • Multiple animation names from the same skeleton.
  • Source-origin proof records with SHA-256 file hashes, GitHub commit receipts, browser/account evidence hashes, and optional blockchain anchors.
