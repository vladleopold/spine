What this Spine preview page is for

This page explains the core Spine preview workflow in Spine-Link. The tool is designed for exported animation packages: a Spine skeleton file, an atlas file and one or more texture images. After loading, the browser player shows the animation list, playback controls, loop settings, PMA and blend preview options.

Preview Spine JSON and SKEL files without installing the Spine editor.
Check atlas and texture loading in a browser-based Spine web player.
Choose one animation from a skeleton that contains multiple animation names.
Create permanent preview links for review and production feedback.

How to preview Spine files online

  1. Export the files from Spine.

    Use a JSON or SKEL skeleton file, the matching atlas file and all texture images referenced by it.

  2. Open Spine-Link in your browser.

    Drag the files into the preview area or select them from the file picker.

  3. Select the animation to review.

    Switch between animation names and check playback, loop behavior, PMA and blend settings.

  4. Create a preview link when needed.

    Generate a permanent browser URL so another person can review the Spine animation without a zip file.

Spine preview FAQ

What Spine files can I preview online?

Spine-Link previews Spine JSON or SKEL files together with atlas files and PNG, JPG, JPEG or WEBP textures.

Can I preview several animations from one skeleton?

Yes. When the skeleton contains several animation names, Spine-Link lists them so you can switch playback.

Can I share a Spine preview without sending a zip archive?

Yes. You can create a permanent browser preview link for review, QA, client feedback or portfolio checks.
