# library_02 — сборка Spine-анимаций

> Постоянная папка сбора. Загрузки новых работ идут сюда, пока в `library`
> не наберётся 999 папок. После этого содержимое переносится в `library_03`,
> `library_04` и так далее — папки не переполняются, сайт продолжает читать
> все сборки.

## Период сборки

| | |
|---|---|
| **Начало** | октябрь 2026 |
| **Текущее состояние** | идёт набор |
| **Предел папки** | 999 каталогов |

Когда папка заполнится, период будет дописан сюда как `месяц — месяц`,
а работы переедут в следующую папку сборки.

## Состав

## Как это работает

- `library/` — папка набора. Сюда попадают новые работы.
- `library_01`, `library_02`, … — постоянные сборки. Их не трогают, они только
  растут до 999 папок и замирают.
- Ротация происходит автоматически: при 999 папках в текущей папке набора
  GitHub Actions создаёт следующую сборку и переносит работы.
- `index.json` внутри папки — список работ, по нему сайт строит витрины.

## Структура

```
library_02/
├── README.md        ← этот файл
├── index.json       ← список всех работ сборки
├── metrics.json     ← лайки и просмотры
└── <работа--id>/     ← папка одной работы: скелет, атлас, текстура, видео
```

## Карточка работы

Каждая работа — отдельная папка с именем `<название>-<дата загрузки>`, внутри:

- `*.json` или `*.skel` — скелет Spine
- `*.atlas` + текстура
- `preview.webm` — превью-видео анимации
- `*-preview.webp` — постер для карточки

## Как пользоваться

Публичная витрина: `https://spine-link.vercel.app/world-spine-archive`
Страница отдельной работы: `https://spine-link.vercel.app/p/<работа-id>`

Сборка ведётся автоматически. Период и состав обновляются при ротации папок.
